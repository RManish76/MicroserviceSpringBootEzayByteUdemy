*1* Creation of 1st chart

        As we know that heml is package manager like pip in python.
        helm helps in mitigate the manual work which we were doing eariler with Kubernetes cluster.
        like mannually executing command to start/apply new manifest file, mannually running cmd for
        rollout, rollback. Also we have to do it 1 by 1 for each manifest.

        Helm will create single file/chart which will allow to execute manifest file for within from a
        single chart also rollout, rollback of whole cluster etc.

        1st create the helm char with command: helm create <chartName>
            executed: helm create eazybank-common

        After executing above command a folder will be created with name eazybank-common in the folder
        where command got executed.
        So whenever we create a helm char using above command, it gives some predefined templates and yaml files

        Since we want to create our own chart we'll remove the templates folder and the file within that chart.
        Also the values present in values.yaml, we are not going to use, so will remove that as well.

        And others are fine.

        Copy pasted the files in templates folder from instructor git repo.

        For better understanding of files follow the order as
            1st service.yaml       2nd deyployment.yaml           3rd configmap.yaml
