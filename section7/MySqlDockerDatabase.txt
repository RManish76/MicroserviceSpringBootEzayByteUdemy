*2* Install and run the mySQL docker

    >> docker run -p 3306:3306 --name accountsdb -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=accountsdb -d mysql

    3306 --> default port of mySQL
    --name --> name of the container which we want. else random name will be assigned by docker
    -e --> saying next element is enviorment variable
    MYSQL_ROOT_PASSWORD --> root password of the database. we have give root as pasword and username is root by default
    MYSQL_DATABASE  --> by default when we install any database, it does not have any schema/server installed.
                        we want to create a schema/server in database and the name is accountsdb
    -d --> to run the docker in detached mode
    mysql --> the name of the image which we want to download

    similary we created the container for loans at port 3307 and cards at port 3308
    >> docker run -p 3307:3306 --name loansdb -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=loansdb -d mysql
    >> docker run -p 3308:3306 --name cardsdb -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=cardsdb -d mysql
