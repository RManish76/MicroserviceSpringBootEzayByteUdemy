*2* Creation of eurekaserver MS
    Below dependency were involved in this project from spring initalizer
        Eureka Server(Spring Cloud Discovery): this dependency will help us to store the api of other MS.
                                                Bascily this dependency will make this MS act as registry
                                                which will maintain the api links of other MS.
                                    
        Config Client(Spring Cloud Config): This is the dependency which helps to fetch profile/configuration
                                            from external soruce(Config Server MS).

        Spring Boot Actuator(OPS): Supports built in (or custom) endpoints that let you monitor and
                                    manage your application - such as application health, metrics, sessions, etc.

*3* Make changes for eurekaserver
    Added @EnableEurekaServer in root java file/ EurekaserverApplication.java
        @EnableEurekaServer --> using this annotation we are trying to convert a normal springboot to act as
                                a service Discovery agent with help of eureka service library which we added in pom.

    Added details in application.yml
        ConfigServer Details -> so that profiles can be fetched from the server for different instances
        Health checkup -> we also enabled managment/Actuator in application.yml to prob the health status
                            of eurekaserver MS as we want the eurekaserver MS running and healty before the accounts,
                            loans and cards MS runs.

    Added remaining properties of application.yml in git repo
        Added a file eureakserver.yml in git repo which stores additional config details which we
        do not want to keep in application directly.
        if notice we have only one profile in git repo which eureakserver.yml not like defaul,qa and prod
        it's becasue our eurekaserver will behave same in all instances hence multiple profile not required.
        below is code.

                server:
                    port: 8070
                eureka:
                    instance:
                        hostname: localhost
                    client:
                        fetchRegistry: false #to not fetch registry from other reigstry service(we also do not have other registry). By default true.
                        registerWithEureka: false #to not registr it self on the registry. Mean we don't want the current registry expose itself on it's own registry. By default true
                        serviceUrl:
                            defaultZone: http://${eureka.instance.hostname}:${server.port}/eureka/  #where the eureka server is going to expose its functionality and other MS to register & discover the details


*4* Making changes in accounts, loans, and cards MS
    Now we'll update the accounts, loans and cards MS so that they can register themselv over
    eurekaserver and also send the heartbeat to eureakserver automatically.

    Added eureka-client dependency in accounts MS pom file.
		<!-- EurakClient to register to eureakServer and send heartbeat -->
		<dependency>
			<groupId>org.springframework.cloud</groupId>
			<artifactId>spring-cloud-starter-netflix-eureka-client</artifactId>
		</dependency>

        Now we'll update the application.yml file of accounts MS for eureka client
            #eureka server details --> As accountsMS is eureka client, it need details of eureka server to connect to eureka server
            eureka:
                instance:
                    # hostname: localhost #no need in client as it's not a server
                    preferIpAddress: true #by default cliet register themselv using hostname and it works when we have DNS mapping.
                                        #But in our local we don't have any DNS, so we should prefer IP address so that they can find each other
                                        #using IP address
                client:
                    fetchRegistry: true #to not fetch registry from other reigstry service(we also do not have other registry). By default true.
                    registerWithEureka: true #to not registr it self on the registry. Mean we don't want the current registry expose itself on it's own registry. By default true
                    serviceUrl:
                        defaultZone: http://localhost:8070/eureka/  #where the eureka server is going to expose its functionality and other MS to register & discover the details

            #details which we want to show at eureka server for this app.
            #these infor information will be exposed as part of an actuator endpoint URL
            #Since by default the infor related actuator URL is not enabled, we need to enable the same by adding
            #a property under management followed by info.
            info:
                app:
                    name: "accounts"
                    description: "Eazy Bank Accounts Application"
                    version: "1.0.0"

        Also added actuator endpoint to enable shutdown and added enpoints expose to shutdown the application
